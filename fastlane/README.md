# The Android app's listing, for F-Droid

F-Droid reads the app's listing from `metadata/android/<locale>/`, in fastlane's layout. It is the Google Play
listing as published: the title, short and full descriptions and the feature graphic in Play's ten languages, and
the en-US phone screenshots and icon (`public/icon-512.png`), which F-Droid shows in the other languages too.
Change it with the Play listing.
